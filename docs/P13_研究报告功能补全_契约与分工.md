## 4. 各任务验收标准

1. **A0**：真机上出现「原始观测与导航电文」卡；测量数>0、DOP 三值 + TTFF 有值或 N/A 带原因、导航电文条数可增长；DopTest ≥5 例全绿；`registerGnss*Callback` 在 awaitClose 反注册。
2. **A1**：`OperatorTableTest` ≥6 例（非重叠/边界/空集/跨制式隔离）；真机蜂窝页服务小区出现「运营商归属（换算）」，未收录频点显示 N/A+原因；docs 参考文档含 ≥2 独立来源逐条对账。
3. **A2**：邻区按制式分组显示（NR→LTE→WCDMA→TDS→GSM→CDMA），组内仍按键排序。
4. **A3**：设置页可勾选 CSV 列（最小必需列不可剔除），覆盖测试页显示生效列集；`exportCsvWith` 单测覆盖列过滤与必需列并入。
5. **B6**：`DriveKpiTest` ≥5 例；覆盖测试页 KPI 卡随权重变化（设置页滑条联动）。
6. **B4**：`GeoMathTest` ≥4 例（含跨 ±180°）；测速页可添加/选用/删除端点；「就近选点」在定位可用时可选最近端点；不内置第三方节点库。

## 6. 纪律（全员）

- 三态口径：`FieldValue.measured/derived/estimated/unavailable(reason)`；N/A 必带原因；估算必带声明；禁止 0/-1/占位伪装。
- 数据诚实：OperatorTable 单源条目不收录；NR-ARFCN DL 口径假设沿 BandTable 既有声明。
- 不复制 Cellular-Pro 任何资产（服务器列表/配置表/资源）。
- 文件写入一律 read/edit/write 工具（UTF-8）；禁 `Set-Content/Out-File` 回写。
- 构建成败只认 `BUILD SUCCESSFUL/FAILED` 行，禁止截断 gradle 输出后判读。
