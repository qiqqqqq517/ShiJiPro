## 1. 换算口径

3GPP TS 36.101 §5.7.3：`F_DL = F_DL_low + 0.1 × (N_DL − N_offs)`，反解 `N_DL = N_offs + 10 × (F_DL − F_DL_low)`。
区间取**闭区间**，上界 = 频率上界换算值 − 1（避免把下一段起点计入本段）。

## 3. 明确未收录（宁缺勿错）

| 项 | 原因 |
|---|---|
| B41 2515–2575 与 2635–2675 的归属 | 移动/联通/电信三方再划分在各公开资料中不一致（有 2555–2575 / 2635–2675 等多种说法），无法双源确认 → 不收录，查询返回 N/A「不猜」 |
| NR（n41 / n78 / n28）全部 | 需叠加 3GPP TS 38.104 的 NR-ARFCN 全局栅格与工信部分配边界逐段核对，本轮未完成；`NR_RANGES` 为空、`forNrArfcn` 恒 null → UI 显示 N/A + 原因 |
| 广电 700MHz（B28/n28） | 来源仅覆盖「获批」层面，EARFCN 边界无两源印证 → 不收录 |

## 5. 使用与降级

- 命中 → `FieldValue.derived(operator, "bandN · EARFCN low–high（换算，公开频谱分配）")`，UI 显示「换算」徽标。
- 未命中 → `FieldValue.unavailable("该 EARFCN(x) 不在已收录的运营商子频段内（不猜）")`。
- 制式非 LTE/NR → N/A + 原因「运营商归属只覆盖 LTE/NR（该制式未收录）」。
